# agentic-AI-as-POMDP
Toy example of validating agentic AI as a POMDP

You're need API keys for Massive.com and Open AI. Set them as environmental variables: 

export MASSIVE_API_KEY="..."

export OPENAI_API_KEY=".. "

RUN_OPENAI=1

then
pip install -r requirements.txt
python portfolio-agent-test.py

The paper is available here: https://quiota.substack.com/p/agentic-ai-as-a-partially-observable?r=9a1il
